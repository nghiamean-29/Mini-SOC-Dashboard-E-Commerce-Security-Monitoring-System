E-Commerce Security Monitoring

Website thương mại điện tử có Mini SOC giám sát

Mọi hành động quan trọng trong shop — đăng nhập, truy cập bị từ chối, đặt hàng — được ghi lại thành security event. Các rule phát hiện tấn công (brute force, SQL injection, request flood…) biến những event đó thành alert, rồi thành incident để analyst điều tra.

Xin chào, bạn

Tài khoản của bạn đang có các quyền:

  • CUSTOMER — mua hàng
  • ADMIN — quản trị shop + xem SOC
  • SOC_ANALYST — giám sát an ninh

Dòng chảy dữ liệu an ninh

  1. 1

    Thu thập

    Filter + listener ghi security_events: đăng nhập, 403, thao tác quản trị, đơn hàng.

  2. 2

    Phát hiện

    5 rule chạy trên cửa sổ trượt trong bộ nhớ: brute force, truy cập trái phép, flood, SQLi, chiếm tài khoản.

  3. 3

    Cảnh báo

    Alert có mức độ, có bằng chứng (các event gốc) và được khử trùng lặp theo cooldown 5 phút.

  4. 4

    Điều tra

    Alert cùng nguồn được gom thành incident; analyst gán, ghi chú, resolve và lưu vết audit.

Trạng thái dự án

Đang ở Phase 3 — Authentication & Authorization. Trang chủ, đăng nhập và đăng ký đã hoạt động; sản phẩm, giỏ hàng và dashboard SOC sẽ lần lượt xuất hiện ở các phase sau.
